# UI/UX 迭代方案 · 参考四仓库后

> 参考对象：`pbakaus/impeccable`、`joeseesun/qiaomu-design`、`joeseesun/qiaomu-cover-design`、`joeseesun/qiaomu-mondo-poster-design`
> 对照基线：`docs/DEV-PLAN-2026-11-03.md`、`docs/AUDIT-2026-11-03.md`、`UIUX-PLAN-2026-11-03`（站主提供，未入库）
> 现状实测：令牌 62、`design-lint` 808/808、`src/pages/*.js` emoji 49 处、`DESIGN.md` 29,345 B 但**未入库**

## 0. 结论先行

这四个仓库真正的价值不在视觉模板，而在三种**机制**：

| 机制 | 出处 | 我们的状态 |
|---|---|---|
| 可判定的检测器（62 条规则，无需 LLM，可跑 CI） | impeccable | 只有 7 条令牌规则，缺"AI 味"维度 |
| 决策前移的试衣间（4 个轴级互斥方向，真实页面点选） | qiaomu-design | **完全没有**，改 UI 直接写代码 |
| 产物与源分离的纪律 | qiaomu-cover-design | **已有且更强**（哈希产物 + `check-build-sync`） |

一句话：**工程门我们已经强于它们，决策流程与删减通道是我们的空白。** 所以方案的重点不是"换一套视觉"，而是补流程。

## 1. 四份资料：借什么、不借什么

### impeccable — 借"检测器"，不借"整套 agent 生态"

| 可迁移 | 具体做法 |
|---|---|
| 62 条确定性规则 | `npx impeccable detect <url>` 直接扫真实渲染页，退出码 2 = 有发现，无需装 skill |
| 发现分级 P0–P3 | 我们的 `design-audit` 目前只报数，应加严重度 |
| 单组件迭代优先 | "一个 section 认真看"胜过"整页扫一眼"，与我们日卡改造一致 |
| 反 slop 的根源诊断 | 无指引时 agent 必产出：Inter + 紫蓝渐变 + 卡片套卡片 + 彩色底灰字 + 每个标题上的圆角图标磁贴 |

不借：24 命令全套（单人产能撑不住）、把 skill 装进仓库（引入外部 agent 依赖与 telemetry）、`live` 模式（需注入页面并放宽 CSP，与我们刚上的 CSP 直接冲突）。

### qiaomu-design — 借"流程"，不借"风格库"

| 可迁移 | 具体做法 |
|---|---|
| 六段闭环 | 发散 → 定义 → 选择 → 独立评审 → 删减 → 真实验收 |
| 4 个**轴级互斥**方向 | 不是同一方案的深浅变化，必须在结构轴/信息轴/交互轴上不同 |
| 三拨盘 | `VARIANCE` 冒险度、`MOTION` 动效、`DENSITY` 信息密度，随方向一并回传 |
| 反 slop 禁令 | 紫渐变 / Inter / 斜体 / 居中 Hero / "revolutionary / seamless" 类文案 |
| 中文排版纪律 | 正文系统字体栈优先；装饰标题**按实际字符子集化**（完整 CJK webfont 5–20 MB，默认禁用） |
| 审查输出 `file:line` | 可定位，不接受"整体感觉不好" |
| 偏好账本 | 用户反馈沉淀为规则，最高优先级 |

不借：58 站 `DESIGN.md` 迁移库（抄皮相）、K3 外派实现、AI 生图。我们的纸感 `#FAFAF7` + 朱红 `#B71C1C` + 印章金 `#C9A227` 已有辨识度，缺的不是风格样本。

### qiaomu-cover-design — 借"安全区"与"换比例三分支"

| 可迁移 | 具体做法 |
|---|---|
| 双产物（源 + 成品） | 正好印证我们的 `src/` → `assets/`，纪律已成立 |
| 安全区 / 吸附 | 移动端 `env(safe-area-inset-*)`；底部 tab bar 与现场主屏必须避让 iOS 手势区与浏览器 UI |
| 换比例三分支 | 模板创建 → 重算锚点；自由元素 → 按比例适配；纯手工 → 缩放。对应我们"日卡 / 地图面板 / 现场主屏"三种布局来源 |
| 对比度兜底 | 低对比时描边或调深——我们已有真实浏览器审计，更强 |

不借：12 平台画幅预设（我们只有手机与桌面两档）、34 个字体 31 MB、Fabric.js 画布。

### mondo-poster — 借"极端约束"，且只用于符号设计

| 可迁移 | 具体做法 |
|---|---|
| 限色 2–5 | 城市标识只允许 2 色（主色 + 纸色），不引入新色 |
| 一个符号承载整体 | 9 个城市各一个极简几何符号，用于地图图例与日卡角标；这是**可选资产**，不进本轮 |

不借：整站海报化、33 位艺术家风格库、生图脚本。

## 2. 现状对照：我们强在哪、缺在哪

| 维度 | 本项目现状 | 参考方 | 判断 |
|---|---|---|---|
| 令牌强制 | L1–L7 棘轮，808 处基线，只降不升 | qiaomu 有 token，无棘轮 | **我们更强** |
| 对比度 | 真实浏览器审计（`continue-on-error`） | cover-design 只写"描边或调深" | **我们更强** |
| 产物纪律 | 哈希产物 + `check-build-sync` + 引用门 | cover-design 双产物 | **我们更强** |
| 反 AI 味 | 只禁"字面量颜色"，无风格规则 | impeccable 62 条 | **缺** |
| 决策前移 | 无，直接写码 | qiaomu 4 方向试衣间 | **缺** |
| 删减通道 | 无，日卡 22–38 个按钮还在加 | `distill` / 删减 | **缺** |
| 设计意图解释层 | `DESIGN.md` 29 KB，**未入库**（审计 N11） | PRODUCT.md / DESIGN.md 均入库 | **缺一步** |

## 3. 三阶段方案

### Phase 0 · 零改动先量一次（0.5 天，本周）

目标：拿到"AI 味"的客观数字，再决定补什么。**不改任何代码。**

```bash
npm run dev                                   # 起 dev server
npx impeccable detect http://127.0.0.1:8080    # 扫真实渲染页（对比度、微字号需渲染）
npx impeccable detect src/                     # 扫源码（只有模式规则）
npx impeccable detect --list-rules             # 导出全部规则 id + 描述
```

产出：把 62 条与本项目 L1–L7 做差集，得到三张单子——「已覆盖 / 值得补 / 不适用」。

同一阶段做一件低风险的事：**`DESIGN.md` 脱敏入库**（去掉个人路径、内部链接、任何 Key），堵 N11。它同时是 impeccable `document` 概念里的产物，也是 qiaomu 的"锚"。

验收：能明确回答"62 条里我们已有 N 条、值得补 M 条、不适用 K 条"；`git ls-files DESIGN.md` 非空。

### Phase 1 · 决策前移：只做两个高不确定项（1 天）

不做全站试衣间。只对**改错代价最高、争论最多**的两处做：

1. **日卡分层**（DEV-PLAN L6，直接服务于 Trip Lint 的证据徽章）
2. **现场主屏**（UIUX U4，与 Leaflet 层级冲突最大）

规则（借 qiaomu 的"轴级互斥"）：

- 4 个方向必须在**轴**上不同，不是同一方案的深浅
- 每个方向是**真实 HTML**（真字体、真配色、真数据），不是效果图
- 放 `design-previews/2026-11-XX-日卡分层/index.html`，离线可开，键盘 `1–4` 选择
- 选完在 `docs/DESIGN-DECISIONS.md` 记一行：日期 / 选中项 / 理由 / 反悔成本

日卡分层的四个轴（示例，拍板时可替换）：

| 方向 | 轴 | 形态 |
|---|---|---|
| A | 折叠深度 | 摘要行 + 「调整」抽屉（保守，改动最小） |
| B | 呈现介质 | 6 张卡压成一条时间轴单列 |
| C | 联动关系 | 卡片与地图点位双向高亮 |
| D | 密度可调 | 紧凑 / 标准 / 详细三档切换 |

三拨盘取值（借 qiaomu）：

- 日卡分层：`VARIANCE` 低、`MOTION` 低、`DENSITY` 高（要装下证据徽章）
- 现场主屏：`VARIANCE` 中、`MOTION` 中、`DENSITY` 低（单手、阳光下、可能戴手套）

验收：站长在真实手机尺寸下点选一个方向并写下理由；未选中方向的成本已知。

### Phase 2 · 删减与落地（2–3 周，并入既有排期）

| 项 | 内容 | 工时 | 归属 |
|---|---|---|---|
| 日卡分层 | 摘要行常驻（日期 + 时段 + `structural` 结论 + 证据徽章 + 1 个主操作）；减负/延收工/解锁/删重/移到预订/打车/优化顺序收进「调整」 | 1.5 d | DEV-PLAN L6 |
| emoji → SVG | 49 处一次做完，`src/shared/icons.js` 内联 SVG，不引第三方库 | 2 d | UIUX U2，顺延至第 10–12 周 |
| 移动端安全区 | 底部 tab bar 与现场主屏加 `env(safe-area-inset-*)`，底部操作区不压 iOS 手势条 | 0.5 d | 新增，低成本 |
| 渲染门翻牌 | 连续 3 轮 `design-audit` 数字稳定后去掉 `continue-on-error` 与 `--report-only` | 0.2 d | 条件式 |

## 4. 反 slop 规则：补 6 条，但**都不阻断**

**纪律前提：DEV-PLAN 已冻结新增质量门 12 周。以下规则一律先进报告，基线从 0 起，连续 3 轮稳定才谈翻牌。**

| 规则 | 查什么 | 归属 | 阻断 |
|---|---|---|---|
| S1 渐变禁令 | `linear-gradient` 两色 hue 差 > 90 且落在 200–280（紫蓝区） | `design-lint` 静态 | 否 |
| S2 嵌套卡片 | 同一 DOM 路径 ≥2 层「圆角 + 非透明背景」 | `design-audit` 浏览器 | 否 |
| S3 图标磁贴 | 每个标题前都有圆角容器包 icon（模板化特征） | `design-audit` | 否 |
| S4 全量 CJK webfont | `@font-face` 缺 `unicode-range` 且 `.woff2` > 1 MB | `design-lint` | 否 |
| S5 居中 Hero | 首屏 `text-align:center` + 单 CTA 居中 + 全宽渐变 | `design-audit` | 否（本项目大概率不适用，仅记录） |
| S6 emoji 当图标 | `src/pages/*.js` emoji 计数（当前 49） | `design-lint` 棘轮 | **是**（复用现有棘轮：49 设为基线，只准降） |

S6 是唯一能立刻阻断的一条，因为它复用已有机制、不新增门：把 49 写进 `design-lint-baseline.json`，之后每改一处降一处，想回升就红。

## 5. 明确不采纳

| 项 | 理由 |
|---|---|
| 33 位艺术家风格库 / 58 站 DESIGN.md 迁移 | 抄皮相；我们的纸感 + 朱红 + 印章体系已有辨识度，缺的是结构不是皮肤 |
| AI 生图与海报生成 | 与离线 PWA、首屏预算（JS 512 KB）冲突 |
| 34 个 CJK 字体（31 MB） | 移动端首屏不可接受；装饰标题只做字符子集 |
| 24 命令全量安装 | 单人产能撑不住；只取 `critique` / `distill` / `polish` 三个动作的思路 |
| `impeccable live` 模式 | 需向页面注入脚本并放宽 CSP，与我们刚上线的 CSP 直接冲突 |
| 把 impeccable 写进 `package.json` | Phase 0 只用一次 `npx`，不引入长期依赖 |

## 6. 与既有计划的关系

- **不新增第三条线**：Phase 1 的试衣间服务于 DEV-PLAN L6；Phase 2 的现场主屏仍在第 6 周胶囊实测之后
- 工时合计：Phase 0 0.5 d + Phase 1 1 d + Phase 2 4.2 d，全部落在既有 WIP ≤ 2 的约束内
- 新增产出物只有三个：`docs/DESIGN-DECISIONS.md`、`design-previews/`（可 `.gitignore`）、`DESIGN.md` 入库

## 7. 本周就能做的三件事

1. `npx impeccable detect http://127.0.0.1:8080` —— 零改动、半小时、可回退
2. `DESIGN.md` 脱敏入库 —— 半小时，堵 N11，让"为什么 12px 下限、为什么 39b"不再只存在一台机器上
3. 日卡分层的 4 个方向 —— 半天，产出可点击的真实页面，而不是形容词

## 8. 一个提醒

参考方都强调"实现者不能自评"。本项目目前的设计质量判断只有一道 `design-audit` 的数字，没有独立评审环节——**我改的界面由我来判断好不好看，这本身就是偏差来源**。Phase 1 的试衣间加上"你点选、我记录理由"，是当前产能下最便宜的一层隔离。
